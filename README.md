# 📊 Trabalho 1 - Estruturas de Dados I
### Análise de Complexidade e Tempo de Execução de Algoritmos


## 🎯 Descrição do Projeto
Este projeto foi desenvolvido para a disciplina **Estruturas de Dados I (SCC0202)** no **ICMC-USP**.  

O objetivo é implementar e analisar empiricamente a **complexidade e o tempo de execução** de quatro algoritmos fundamentais:

- Inversão de vetor  
- Busca sequencial  
- Busca binária iterativa  
- Busca binária recursiva  

O programa principal, implementado em **C**, realiza as operações e mede o tempo médio de execução para diferentes tamanhos de entrada (`10, 100, 1000 e 5000`).  

Para automatizar a compilação, a execução dos testes (média de **100 execuções por entrada**) e a visualização dos dados, foi utilizado um **script em Python** com a biblioteca **Matplotlib** para gerar os gráficos de performance.

---

## ✨ Funcionalidades
- [✔] **Inversão de Vetor** → Inverte a ordem dos elementos de um vetor de entrada.  
- [✔] **Busca Sequencial** → Realiza uma busca linear em um vetor ordenado.  
- [✔] **Busca Binária Iterativa** → Busca binária em vetor ordenado com abordagem iterativa.  
- [✔] **Busca Binária Recursiva** → Busca binária em vetor ordenado com abordagem recursiva.  
- [✔] **Análise de Pior Caso** → Todos os testes de tempo são conduzidos no pior caso de cada algoritmo.  
- [✔] **Geração de Gráficos** → Criação automática de gráficos de tempo de execução (**N vs. Tempo**) salvos em uma pasta dedicada.  

---
